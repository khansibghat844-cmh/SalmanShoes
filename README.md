# Salman Shoes - Portfolio / Online Shoe Store
Pages: Home, Services, Skills, Experience, Contact Us. HTML + CSS + JavaScript only. Mobile and desktop friendly.

## Setup
1. Open `js/script.js` and change `CONFIG.wa` to your WhatsApp number (country code, no `+`), e.g. `923001234567`.
2. Put your shoe photos in `images/` using the file names listed in `PRODUCTS` (or edit the names). Add `images/hero.png` for the banner.
3. Edit names and prices in `PRODUCTS` inside `js/script.js`.
4. Edit text in the `.html` files (Skills and Experience content are sample text).

## Upload to GitHub Pages
1. Create a new repository on github.com.
2. Upload all files, or use: `git init`, `git add .`, `git commit -m "Salman Shoes"`, `git remote add origin <repo-url>`, `git push -u origin main`.
3. Repo > Settings > Pages > Branch: `main` / root > Save. Site goes live at `https://<username>.github.io/<repo>/`.
